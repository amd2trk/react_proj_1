# START FRAMEWORK - Portfolio Website

A modern, responsive portfolio website built with React, showcasing a clean and professional design for freelancers and creative professionals.

## 🌟 Features

- **Responsive Design**: Fully responsive layout that works seamlessly across desktop, tablet, and mobile devices
- **Single Page Application**: Fast navigation with React Router for smooth page transitions
- **Interactive Portfolio Gallery**: Image modal viewer with hover effects and smooth animations
- **Contact Form**: Professional contact section with floating label inputs
- **Active Navigation**: Dynamic navigation bar with active state indicators
- **Modern UI**: Built with Tailwind CSS and Flowbite React components

## 🚀 Live Demo

[View Live Demo](https://react-proj-1-taupe.vercel.app)

## 📋 Pages

- **Home**: Hero section with avatar and introduction
- **About**: Information about skills and background
- **Portfolio**: Interactive image gallery with 6 project showcases
- **Contact**: Contact form for client inquiries
- **404 Page**: Custom not found page for invalid routes

## 🛠️ Built With

- **React 19.2.0** - JavaScript library for building user interfaces
- **React Router DOM 7.11.0** - Declarative routing for React applications
- **Tailwind CSS 4.1.18** - Utility-first CSS framework
- **Vite 7.2.4** - Next-generation frontend build tool
- **Flowbite React 0.12.15** - Component library built on Tailwind CSS
- **FontAwesome 7.1.0** - Icon library for web projects

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/amd2trk/react_proj_1.git
cd react_proj_1
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`

## 🔧 Available Scripts

- `npm run dev` - Starts the development server
- `npm run build` - Builds the app for production
- `npm run preview` - Preview the production build locally
- `npm run lint` - Run ESLint to check code quality
